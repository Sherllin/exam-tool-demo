# 考试工具 Demo 设计

## 目标

在桌面创建一个可独立运行的 Next.js + FastAPI Demo，实现 PRD V1.0 本期范围：当前考试的成绩打印轻量配置，以及同一考试、同一年级多个班级的总分和各科平均分基础表格。额外接入一个不会修改成绩数据的 LLM 标题建议能力。

## 优先级与范围

- PRD 高于 Figma；Figma 仅决定整体布局、颜色、字号、间距和导航结构。
- 实现字段显隐、字段顺序、基础标题、配置后打印预览和浏览器打印。
- 实现单次考试、同年级、多班级、总分平均分和各科平均分表格。
- 不实现模板保存、模板复用、多模板、排名分析、跨考试趋势、柱状图或自动诊断。
- 不实现英语作文 AI 阅卷；LLM 仅生成可编辑的成绩单标题建议。
- 使用标明为脱敏演示数据的数据集；真实客户样例未提供，因此界面提示“待真实样例复核”。

## 架构

项目为单仓库，`frontend/` 使用 Next.js App Router、React、TypeScript 和原生 CSS，`backend/` 使用 FastAPI、Pydantic 和 httpx。Next.js 将 `/api/*` 转发至 FastAPI，浏览器只访问一个前端源。Demo 不引入数据库，打印配置保存在当前页面状态；刷新页面恢复默认值。

FastAPI 提供健康检查、首页摘要、打印数据、班级平均分以及 LLM 标题建议接口。LLM 通过 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL` 配置兼容 Chat Completions 的服务；配置缺失或上游失败时返回明确标识的本地演示建议，保证 Demo 可运行。

## 页面

### 成绩发布总览 `/`

沿用原型的 240px 深色侧栏、64px 顶栏、浅灰背景、白色卡片和品牌蓝。展示本次考试、演示数据状态、打印配置入口与班级平均分入口。删除原型中无材料依据的接口闭环、AI 准确率和模板数量承诺。

### 打印配置 `/print`

左侧为配置区：标题输入框、LLM 标题建议按钮、字段显隐复选框、字段上移/下移、应用和恢复默认。右侧为当前配置的成绩单预览，展示考试、班级和脱敏学生成绩。至少保留一个可见字段；点击“应用到预览”后才改变预览，点击“打印当前预览”调用浏览器打印。

### 班级平均分 `/comparison`

展示固定的当前考试和年级范围，表格每个班级一行，列为班级、参考人数、总分平均分、语文、数学、英语。无排序、导出、排名、趋势、图表和自动结论；统计口径明确标记为 Demo 口径，待业务确认。

## 接口与数据流

- `GET /api/health`：服务健康状态。
- `GET /api/dashboard`：考试摘要与本期能力状态。
- `GET /api/exams/{exam_id}/print-data`：可配置字段和脱敏学生成绩。
- `GET /api/exams/{exam_id}/class-averages?grade=高二`：同考试、同年级的班级平均分表格。
- `POST /api/llm/title-suggestion`：输入考试、年级和材料类型，输出标题及 `provider` 或 `fallback` 来源。

前端页面加载时调用对应接口。请求失败时在页面显示可重试错误，不把错误伪装为空数据。LLM 超时、响应格式错误或凭据缺失均降级为本地建议，并显示降级原因。

## 视觉规范

- 1440px 原型基准，自适应窄屏；侧栏 240px，顶栏 64px。
- 中文字体栈优先 PingFang SC；主色 `#0060e6`，深色侧栏 `#172033`，背景 `#f4f6f8`。
- 卡片圆角 8px，主要间距 24px；状态标签无边框，使用同色 10% 背景。
- 页面不复制 Figma 的绝对定位，而转换为可维护的 Grid/Flex 布局。

## 测试与验收

后端用 pytest 验证接口范围隔离、打印字段、平均分表格、LLM 本地降级和兼容接口解析。前端用 Vitest + Testing Library 验证导航、字段显隐/顺序、配置应用、LLM 来源提示和平均分列。最终运行后端测试、前端测试、TypeScript 检查、Next.js 生产构建，并启动真实前后端做接口与页面烟测。
